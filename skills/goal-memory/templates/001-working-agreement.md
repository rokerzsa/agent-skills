# Working agreement

The human sets direction and decides consequential choices. The agent inspects existing work, explains its reasoning, asks focused questions and implements authorized work in reviewable slices. A clear instruction may authorize several steps. Explicit instructions override defaults.

Use private memory to preserve important decisions and progress. By default present each slice for review before the next, and commit only when instructed. Record only actual approvals and evidence. See [working patterns](003-working-patterns.md) and the [operating guide](HOW-TO-USE.md).
